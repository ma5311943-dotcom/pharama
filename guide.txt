PROJECT OVERVIEW
================================================================

Project Name:     PharmaEase
Type:             Full Stack Web App
Framework:        Next.js (App Router)
Database:         MongoDB with Mongoose
Auth:             JWT (custom, no NextAuth)
Payment:          JazzCash / EasyPaisa (screenshot upload by user, admin approves)
Medicine API:     OpenFDA  (https://api.fda.gov/drug/label.json)
Roles:            patient | admin

================================================================
FUNCTIONALITIES — PATIENT
================================================================

AUTH:
- Register with name, email, password
- Login with email, password
- JWT token stored in httpOnly cookie
- Protected routes redirect to /login

MEDICINES PAGE:
- Grid of medicine cards (image, name, price, stock badge, add to cart)
- Filter by category
- Sort by price / name
- Pagination

MEDICINE DETAIL PAGE:
- Medicine image
- Name, price, category, stock status
- Description
- Prescription warning label if required
- Drug info pulled from OpenFDA API (dosage, side effects, warnings)
- Add to Cart button

DRUG INFO PAGE:
- Search bar (type medicine name)
- Hits OpenFDA API live
- Shows: brand name, generic name, dosage, side effects, warnings, manufacturer

CART:
- List of added medicines
- Quantity control (increase, decrease, remove)
- Total price
- Proceed to Checkout button

CHECKOUT:
- Order summary
- Delivery address form
- Payment method: JazzCash or EasyPaisa
- Show account number to transfer to
- Upload screenshot of payment
- Place Order button

ORDER TRACKING:
- Order status: Pending → Payment Verified → Processing → Shipped → Delivered
- Admin updates status manually
- Patient sees live status on /orders/[id]

PROFILE:
- Edit name, email, address
- Change password

================================================================
FUNCTIONALITIES — ADMIN
================================================================

DASHBOARD:
- Total sales (amount)
- Total orders count
- Total users count
- Total medicines count
- Low stock alerts
- Recent orders table
- Sales bar chart (monthly)

MEDICINES MANAGEMENT:
- List all medicines with image, name, price, stock, category
- Add medicine (name, description, price, stock, category, image upload, prescription required yes/no)
- Edit medicine
- Delete medicine

ORDERS MANAGEMENT:
- List all orders with patient name, total, status, date
- Click order to see full detail
- View payment screenshot uploaded by patient
- Change order status (Pending / Payment Verified / Processing / Shipped / Delivered / Rejected)

USERS MANAGEMENT:
- List all registered patients
- See name, email, join date, total orders

INVENTORY:
- List medicines with stock count
- Highlight low stock (below 10 units)

================================================================
DATABASE MODELS
================================================================

User:
- name, email, password (hashed), role (patient/admin), address, createdAt

Medicine:
- name, description, price, stock, category, image (url), prescriptionRequired (bool), createdAt

Order:
- userId, items (array of medicineId + quantity + price), totalAmount,
  deliveryAddress, paymentMethod (jazzcash/easypaisa), paymentScreenshot (url),
  status, createdAt

================================================================
API ROUTES (Next.js Route Handlers)
================================================================

AUTH:
POST   /api/auth/register
POST   /api/auth/login
POST   /api/auth/logout

MEDICINES:
GET    /api/medicines              (public, paginated, filterable)
GET    /api/medicines/[id]         (public)
POST   /api/medicines              (admin only)
PUT    /api/medicines/[id]         (admin only)
DELETE /api/medicines/[id]         (admin only)

ORDERS:
POST   /api/orders                 (patient: place order)
GET    /api/orders                 (patient: their own orders)
GET    /api/orders/[id]            (patient: single order)
GET    /api/admin/orders           (admin: all orders)
PUT    /api/admin/orders/[id]      (admin: update status)

USERS:
GET    /api/admin/users            (admin: all users)

UPLOAD:
POST   /api/upload                 (payment screenshot, using multer or cloudinary)

DRUG INFO (proxy to OpenFDA):
GET    /api/drug-info?name=        (hits OpenFDA API server side)

================================================================
PAYMENT FLOW
================================================================

1. Patient selects JazzCash or EasyPaisa at checkout
2. Website shows the account number to send money to
3. Patient sends money manually on their phone
4. Patient uploads screenshot on checkout page
5. Order is saved with status: Pending
6. Admin opens order, views screenshot
7. Admin verifies and changes status to: Payment Verified
8. Order moves forward in pipeline

================================================================
OPENFDAAPI USAGE
================================================================

Base URL: https://api.fda.gov/drug/label.json

Search by name:
https://api.fda.gov/drug/label.json?search=openfda.brand_name:"paracetamol"&limit=5

Fields used:
- openfda.brand_name
- openfda.generic_name
- openfda.manufacturer_name
- dosage_and_administration
- warnings
- adverse_reactions
- indications_and_usage

No API key required. Free to use.
